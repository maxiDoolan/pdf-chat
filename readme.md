# 📄 PDF Chat con IA

Subí cualquier PDF y chateá con él usando inteligencia artificial.

## 🚀 Demo en vivo
[Probalo acá](https://pdf-chat-9znilxxx3rdur3rt8jsdp3.streamlit.app/)
## ✨ Features
- 📄 Subí cualquier PDF
- 📊 Resumen automático en 5 puntos clave
- 💬 Chat con memoria sobre el documento
- 🌐 Respuestas en español, inglés o portugués
- 🗑️ Limpiar historial

## 🛠️ Tecnologías
- Python
- Streamlit
- Groq API
- pypdf

## ▶️ Correrlo localmente
1. Clonar el repo
2. Instalar dependencias: `pip install -r requirements.txt`
3. Crear `.env` con tu `GROQ_API_KEY`
4. Correr: `python -m streamlit run rag.py`
